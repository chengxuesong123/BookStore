# 墨香书屋 · 图书商城 Demo

前端原型，**没有后端**：图书数据写死在 `assets/mock-data.js`，购物车 / 订单 / 登录态用
`localStorage` 模拟，刷新不丢。目的是先看界面和操作流程，不是可上线的版本。

## 怎么打开

推荐用本地服务（避免某些浏览器对 `file://` 的限制）：

```bash
# 在项目根目录
php -S 127.0.0.1:8123 -t demo
# 浏览器打开 http://127.0.0.1:8123
```

也可以直接双击 `demo/index.html`（纯前端 + hash 路由，`file://` 下也能跑）。

## 能体验的流程

1. **首页** → 分类入口、新书上架
2. **全部图书** → 搜索（书名/作者/出版社）、分类筛选、价格排序
3. **图书详情** → 改数量、加入购物车、立即购买；缺货的《围城》按钮是禁用的
4. **购物车** → 加减数量、删除、合计、满 59 包邮提示
5. **结算** → 未登录会被拦到登录页，登录后回跳；收货信息有前端校验
6. **下单** → 生成订单（待付款），扣库存，购物车清空
7. **订单详情** → 「模拟付款」推进到待发货；「确认收货」收尾
8. **我的订单** → 列表、状态、取消未付款订单（取消会回补库存）
9. **后台预览**（导航「后台预览」）→ 图书上下架、订单发货 / 完成

订单状态：`待付款 → 待发货 → 已发货 → 已完成`，另有 `已取消`。

```
├── assets/
│   ├── style.css         全部样式（含响应式）
│   ├── mock-data.js      16 本书、6 个分类

│   └── e2e.mjs           Edge headless + CDP 端到端测试

```

## 跑测试

```bash
# 1. 起静态服务
php -S 127.0.0.1:8123 -t demo

# 2. 启动一个可调试的 Edge（脚本会优先复用这个实例）
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" ^
  --headless=new --remote-debugging-port=9333 --remote-allow-origins=* ^
  --user-data-dir=D:\wamp\php\BookStore\demo\.e2e-profile about:blank

# 3. 跑测试
node demo/tests/e2e.mjs
```

测试覆盖 29 项断言：渲染数量、搜索/筛选、加购与库存上限、缺货禁用、登录拦截与回跳、
表单校验、下单扣库存、状态流转、取消回补库存、后台上下架、404 兜底。

## 和正式版的差距

- 数据全在前端，没有 TP8 接口、没有真实会话与权限
- 金额只在前端算，正式版必须后端重算（这个 Demo 不体现）
- 没有支付、没有图片上传、没有分页（16 本书一次渲染）
- 后台是只读预览 + 两个状态按钮，没有真正的图书 CRUD 表单

这些都在 `docs/产品设计.md` 的里程碑里，接 TP8 时逐条落实。
