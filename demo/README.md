# 墨屿书屋 · 图书商城 Demo

前端原型，**没有后端**：图书数据写死在 `assets/mock-data.js`，账号 / 购物车 / 订单 / 登录态用
`localStorage` 模拟。技术栈 HTML + CSS + 原生 JS + **jQuery 4.0.0**（`assets/vendor/jquery.min.js`）。

## 打开方式

```bash
# 项目根目录
php -S 127.0.0.1:8123 -t demo
# 浏览器打开 http://127.0.0.1:8123
```

也可以直接双击 `demo/index.html`（hash 路由，`file://` 下可用）。

## 账号规则

| 角色 | 账号 | 说明 |
|---|---|---|
| 顾客 | 自行注册邮箱 + 密码 | 注册后自动登录，可下单、看订单 |
| 管理员 | `admin@moyu.com` / `admin123` | 登录成功后**自动进入后台** |

- 登录页有「立即注册」，跳转 `#/register`，用**邮箱**注册（昵称、密码、确认密码）。
- 后台页面**不在前台导航里**。管理员入口只有地址 `#/admin`：
  - 未登录 → 跳登录页并提示「后台入口仅对管理员开放」
  - 已登录但不是管理员 → 弹提示并回首页
  - 管理员登录后才渲染后台

## 页面与流程

1. **首页**：渐变 Hero、浮动书堆、分类精选卡、新书 / 热销列表、服务承诺条
2. **全部图书**：搜索、分类筛选、价格排序
3. **图书详情**：数量加减、加购、立即购买；《围城》设成缺货，按钮禁用
4. **购物车**：数量增减、删除、满 59 包邮、合计
5. **结算**：未登录拦截并回跳；收货人 / 手机号 / 地址校验
6. **订单**：待付款 → 待发货 → 已发货 → 已完成；取消会回补库存
7. **后台**：统计卡、订单管理（发货 / 完成）、图书管理（上下架）

## 动画

jQuery 驱动：卡片逐个淡入上浮、页面切换淡入、购物车角标弹跳、Toast 滑入、
滚动时头部收缩、卡片 hover 抬升、Hero 书堆漂浮、错误字段抖动、按钮按压缩放。

## 与正式版的差距

- 数据全在前端，没有 TP8 接口、没有真实会话与权限校验
- 金额只在前端算，正式版必须后端重算
- 没有支付、图片上传、分页、真实图书 CRUD 表单
- 管理员账号是写死的演示账号，正式版应存库并哈希密码

对应 `docs/产品设计.md` 的里程碑逐步落实。
