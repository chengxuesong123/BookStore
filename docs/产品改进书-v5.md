# 图书商城 产品改进书（v5）

> 版本：v5.0　状态：已实现（2026-11-14）　基线：v4.0（提交 `6bca4c9`）
> 结论先行：**每页/每栏 10 本、分页改成 5 个页码窗口、书库换成 500 本真实书目、封面改成本地生成（外网可用时再换真封面）、头像上传加压缩与强制刷新。** 下面逐条给根因和改法。
>
> 实施结果：500 本真实书目已进 `server/database/books-real.csv`；10 本/页与 5 页码窗口已上线；本地 SVG 书封 `/api/cover/{id}` 已接入；头像改为前端压缩后上传，服务端上限 5MB；接口 40 项、E2E 66 项、Demo 冒烟 12 项全部通过。

## 1. 问题清单与根因

| # | 你看到的现象 | 代码里的事实 | 根因 |
|---|---|---|---|
| 1 | 每个栏目只有 8 本 | `Books.vue`、`Home.vue` 都写死 `page_size: 8` | 分页大小没跟着需求改 |
| 2 | 分页出现 125 页、点下一页页码一直涨 | `Books.vue` 用 `v-for="p in pages"` 把全部页码都渲染出来；`pages = ceil(total/8)`，1000 本 = 125 页 | 缺「页码窗口」逻辑，且每页数量过小 |
| 3 | 书是「方言课」「邻里课」这种 | `generate_seed.php` 用「词根 + 后缀」合成书名 | 种子是生成数据，不是真实书目 |
| 4 | 封面还是没有真正的书封 | 种子 `cover` 为空；Open Library / Google Books 在本机网络不可达（实测超时）→ 前端走渐变占位 | 外部 API 拿不到，且没有本地兜底封面方案 |
| 5 | 头像还是不明显/不显示 | v4 已修 `Content-Type` 和 `:key`，E2E 用真上传验证通过；但你仍看到问题 | 需要区分：旧构建缓存 / 大图超 2MB 被拒 / 上传后未刷新 / 演示模式存档旧 |

## 2. 改进目标

1. 前台所有图书区（首页新书、热销、分类页）**每栏固定 10 本**。
2. 分页只显示 **5 个页码**（当前页居中），配合上一页/下一页；不再一次性渲染 50/125 个页码。
3. 书库改为 **500 本真实书目**（真实书名、作者、出版社、分类），不再生成「XX课」。
4. 封面**默认一定有图**：本地生成书封，不依赖外网；外网可达时再替换成 Open Library / Google Books 真封面。
5. 头像：上传即压缩、上传成功立刻在用户中心与导航栏显示，刷新后仍显示；失败有明确提示。

## 3. 每条的具体方案

### 3.1 每栏 10 本

- 前端：`Books.vue` 的 `page_size` 改 10；`Home.vue` 的新书/热销改 `page_size: 10`（两栏各 10 本）。
- 后端：`/api/books` 的 `page_size` 默认值改 10，上限保持 48；首页两次请求传 10。
- 验收：首页两栏各 10 张书卡；列表页每页 10 张；分类页每类翻页后仍是 10 张。

### 3.2 分页只显示 5 个页码

现状（截图）：1000 本 ÷ 8 = 125 页，全部平铺，越点越乱。

新规则：

```
页数 ≤ 5：全部显示
页数 > 5：显示当前页 ±2 的窗口，固定 5 个按钮
  ‹ 上一页   [3] [4] [5] [6] [7]   下一页 ›
  第 1 页时「上一页」禁用；最后一页时「下一页」禁用
```

- 组件：抽 `Pager.vue`，接收 `page / pages / total`，只负责渲染与 `change` 事件。
- URL 仍然用 `?page=n`，刷新/前进后退可复现（现有行为保留）。
- 列表顶部补「共 N 本，第 X/Y 页」，避免不知道自己在哪。
- 验收：500 本 / 每页 10 = 50 页时，页面最多出现 5 个数字页码；点下一页窗口整体右移一格，不出现 50 个按钮。

### 3.3 500 本真实书目

**目标**：500 条真实存在的书，字段：`title, author, publisher, category, price, original_price, stock, intro, tags`。

**来源与入库方式**（不依赖外网，可重复执行）：

1. 新增 `server/database/books-real.csv`（UTF-8）：一行一本，覆盖 6 个分类，合计 500 条；
2. 新增命令 `php think books:import --file=database/books-real.csv --truncate`：
   - 校验标题唯一、分类存在、价格/库存合法；
   - 批量插入，失败整批回滚；
3. `seed.sql` 只保留管理员与分类，书籍由 CSV 导入（或构建时把 CSV 生成进 seed，二选一，实施时选 CSV 直读，便于你以后替换数据）；
4. 前端不做改动。

**关于「真实」的边界**（需要你确认）：

- 书名、作者、分类按真实书目整理；出版社与定价取常见版本，可能和某一版印次不完全一致；
- 简介由我按书的内容概括，不抄简介原文；
- 不做 ISBN 校验（离线无法核验），如果你要求 ISBN 级准确，需要你提供数据文件或允许联网导入。

### 3.4 封面：本地生成 + 外网机会替换

外网不可达是硬约束（本机 `openlibrary.org` 超时、Google 不通）。所以：

**默认方案：本地生成书封**

- 新增接口 `GET /api/cover/{bookId}.svg`：服务端按书名/作者/分类生成一张 SVG 书封：
  - 分类配色（文学暖棕、历史墨绿、科技藏青、经济金褐、童书蓝绿、社科紫灰）；
  - 书名竖排/两行、作者小字、右下角出版社缩写；
  - 同一本书输出稳定，不随机；
  - 带 7 天缓存头，体积 ~2–4KB，不占带宽。
- `Book.cover` 为空时，前端直接请求这个 SVG；有外网封面 URL 时优先用 URL。
- 效果：**每本书都有像书封的图**，不再是纯色块，也不再出现「没封面」。

**机会方案：外网可用时换真封面**

- 保留 v4 的 `CoverService` 与 `cover:backfill`；
- 新增「封面刷新」按钮（后台图书编辑页）：立即重试一次，成功就写回 `books.cover`；
- 后台列表显示封面来源标记：`外链` / `本地`。

**实测补充（2026-11-14）**：本机浏览器能上网，但 PHP curl 直连 Open Library / Google Books 会超时——系统走了本机代理（`127.0.0.1:7897`），curl 默认不读系统代理，且 PHP 没有 CA 包导致 HTTPS 校验失败。另实测 Open Library 对中文书覆盖率很低（很多书名 `numFound=0`）。已在 v5 中补上：

- `server/.env` 增加 `COVER_PROXY`，`CoverService` 设置 `CURLOPT_PROXY`；
- 仓库自带 `server/database/cacert.pem`，自动用于 `CURLOPT_CAINFO`；
- Google Books 支持可选 `COVER_GOOGLE_KEY`（无 key 会被 429）；
- 中文书增加**豆瓣搜索页兜底**（解析 `__DATA__` 里的 `cover_url`，只取书名匹配的结果）；提供并行脚本 `php database/backfill_douban.php`。

补封面顺序：Open Library → Google Books → 豆瓣 → 本地 SVG。

验收：断网环境下，任意一本书前台都有可辨认的书封（含书名、作者、分类色）；联网时跑 backfill 能把部分书替换成真封面。

### 3.5 头像：压缩 + 即时刷新 + 明确失败

v4 已修掉两个真 bug（手写 multipart 头导致 boundary 丢失；`img` 未加 key 不刷新），E2E 已覆盖并通过。仍要做的加固：

1. **前端压缩**：选图后 canvas 缩到最长边 512px，输出 JPEG(0.85)；手机拍的 5MB 照片也能传，不再触发 2MB 限制；
2. **服务端限制放宽到 5MB**，仍按真实 MIME 校验、随机文件名、旧文件删除；
3. **即时刷新**：上传成功 → 更新 Pinia 用户 → 用户中心预览与导航头像同时换图，url 追加 `?v=时间戳` 防缓存；
4. **可见状态**：上传中按钮转圈/禁用；失败 toast 写明原因（格式、大小、网络）；
5. **降级**：没有头像或图片加载失败时，显示昵称首字渐变圆，不出现破图；
6. **排查提示**（你现在的现象可能是其中一种）：
   - 用了旧构建/旧 Demo：需要重新 `pnpm build:mock` 或强刷；
   - Demo 模式 localStorage 里存的是旧数据：清 `moyu-mock-v4` 再登录；
   - 上传的图片超过限制：v5 压缩后不再发生。

验收：上传一张 3–5MB 的手机照片，用户中心与导航栏 2 秒内同时显示；刷新页面仍在；上传非法文件有明确错误。

## 7. 风险与取舍

| 风险 | 说明 | 对策 |
|---|---|---|
| 「真实书目」的出版社/定价不完全对应版本 | 离线无法逐本核验 | 先按常见版本整理；你提供数据或允许联网后再校准 |
| 本地 SVG 书封不是出版社真实封面 | 只是设计性封面 | 视觉上保证可读、有分类色；联网回填真封面 |
| CSV 500 条体积与维护成本 | 约 80–120KB | 单文件、可编辑、导入命令带校验 |
| 分页窗口逻辑 | 边界（第 1 页/最后页）易错 | 单测 Pager：首页、末页、页数<5、页数=5、跳页 |

## 8. 已确认的三件事（实施依据）

1. **500 本真实书目**：接受「书名/作者/分类真实，出版社与定价取常见版本」的口径；不要求 ISBN 级准确。
2. **封面**：本地生成书封为默认；外网可用时用 `cover:backfill` 回填真封面。
3. **分页**：5 个页码窗口 + 上一页/下一页即可，暂不做「跳到第 N 页」。
